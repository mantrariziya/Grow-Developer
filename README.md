## Why This Project?

Grow Developer needed a professional online presence to showcase their IT services, training courses, and team to potential clients. The goal was a fast-loading, fully static site that could be delivered and hosted without any backend dependency.

## Features

| Feature | Description |
|---|---|
| Services Showcase | Web Dev, App Dev, Graphics, Digital Marketing, Software Dev, Cyber Security |
| Service Detail Pages | Individual pages for Web, Android, Flutter, iOS, Full Stack, Graphics, UI/UX, Digital, Cyber |
| Working Process | 6-step accordion-style process section |
| Industries Covered | Diamond, E-Commerce, Education, Marketplace — tab-based layout |
| Counter Section | Animated odometer counters for years, clients, projects |
| Courses Page | IT training courses listing |
| Team Pages | Individual team member detail pages |
| Testimonials | Swiper-based client testimonial slider |
| Contact Page | Contact form with Google Maps embed |
| Smooth Scroll | GSAP ScrollSmoother for page transitions |
| Back to Top | Animated progress circle back-to-top button |
| Video Popup | Company intro video via Magnific Popup |
| Dark Theme | Default dark theme with smooth loading |
| Mobile Navigation | MeanMenu responsive mobile nav |

## Getting Started

```bash
# Clone the repo
git clone https://github.com/mantrariziya/Grow-Developer.git
cd Grow-Developer

# Open in browser
open index.html
# or use Live Server in VS Code
```

No build step required — pure static HTML/CSS/JS.
